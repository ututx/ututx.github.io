关于

这里记录我在 macOS on DroidVM 方向上的尝试：把 macOS 装进 Android 手机上的 虚拟机里，涉及 UEFI 引导链（UniXNU / DarwinBoot）、设备树（ADT / FDT）、 crosvm 与 Gunyah 虚拟化，以及把整套镜像打包成可导入的 .vmpkg。

项目

  • macOS-DroidVM

    在 DroidVM 里运行 macOS 的镜像构建与引导链调试。

  • vmpkg 工具

    解析与生成 DroidVM 的 .vmpkg 镜像包，支持大文件分卷与完整性校验。

  • 本仓库

    这个 GitHub Pages 站点本身：手写 HTML / CSS，无框架、无构建步骤。
